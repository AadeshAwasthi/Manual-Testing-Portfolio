# Manual Testing Portfolio

![Testing](https://img.shields.io/badge/Testing-Manual-green) ![Docs](https://img.shields.io/badge/Documents-Test%20Plan%20%7C%20Strategy%20%7C%20Reports-blue) ![Status](https://img.shields.io/badge/Project-Demo-orange)

End-to-end manual testing documents prepared by **Aadesh Awasthi** (QA Engineer). This repository shows the complete testing process, from planning to the final report.

> **Note:** This is a **demo project** on [SauceDemo](https://www.saucedemo.com), a public practice website by Sauce Labs. Execution figures in the reports are sample data for portfolio purposes. No company or client information is used.

## Application Under Test

| Item | Details |
|---|---|
| Application | SauceDemo (Swag Labs) |
| Type | E-commerce web application (demo) |
| Modules | Login, Product Listing, Product Details, Cart, Checkout, Navigation Menu |

## Testing Process Followed

```
Requirement Analysis > Test Planning > Test Scenario and Test Case Design
        > Test Execution > Bug Reporting > Retesting and Regression > Test Closure
```
